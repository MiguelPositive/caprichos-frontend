# Pizzería Caprichos - Frontend

Aplicación web desarrollada como proyecto final de la **Tecnología en Desarrollo de Sistemas Informáticos**, orientada a apoyar la gestión administrativa de la **Pizzería Caprichos**.

Este repositorio corresponde al **frontend** del sistema, encargado de la interfaz de usuario y de la interacción con los diferentes módulos de la aplicación.

## Descripción del proyecto

El sistema fue diseñado con el objetivo de apoyar los procesos de:

- Gestión de inventario.
- Administración de productos.
- Facturación.
- Consulta y administración de información.

La aplicación implementa una arquitectura separada entre frontend y backend, permitiendo una mejor organización, mantenimiento y escalabilidad del proyecto.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- React Router
- Axios
- Material UI
- SweetAlert2
- jsPDF
- Moment.js
